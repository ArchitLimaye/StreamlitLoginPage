# Streamlit Login App

A basic login application built using Python and Streamlit. The app allows users to enter a username and password and displays a personalized welcome message with custom emojis after successful login.

## Features

- Username and password input fields.
- Login functionality with credential verification.
- Personalized welcome message after successful login.
- Custom emojis to make the user experience more interactive.
- Simple and user-friendly interface.

## Tech Stack

- **Python** — Application logic
- **Streamlit** — Web interface and user interaction

## Project Purpose

This project was created to explore the basics of Streamlit and learn how to build interactive web applications using Python. It demonstrates user input handling, basic authentication logic, and personalized messages based on login credentials.
